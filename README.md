# Useful program to generate Password

# Use case example:

_Need to generate 16 random ASCII characters_
```console
$ ./pwgen -c 16
```

_The Result_
```console
$ UGm]JR+6n=:![(2?
```

_Need to generate 32 random digit characters_
```console
$ ./pwgen -d 32
```

_The Result_
```console
$ 97058886839470326102846057726054
```

_Need to generate 12 random alphanumeric characters_
```console
$ ./pwgen -n 12
```

_The Result_
```console
$ ACH74PIQhoiT
```
_Need to generate 21 random alphabet characters_
```console
$ ./pwgen -n 21
```

_The Result_
```console
$ lNhSMsqgIFRxputBfOqVA
```
